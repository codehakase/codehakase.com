I build in the open to solve problems I encounter and explore ideas in systems and developer tooling. These are selected projects I've authored or helped develop, followed by earlier open-source work.

## Selected projects

- [snipp](https://github.com/codehakase/snipp) — A minimalist macOS screenshot utility built with Rust and Tauri v2.
- [alpf](https://github.com/codehakase/alpf) — A deterministic framework for agents to retry tasks until a promise is fulfilled.
- [md](https://github.com/codehakase/md) — A fast, lightweight CLI utility for rendering Markdown files with rich formatting and syntax highlighting.
- [Fake.hs](https://github.com/codehakase/Fake.hs) — A minimalist Haskell faker library for generating fake data in tests, built with the State monad.
- [playback](https://github.com/codehakase/playback) — A CLI tool for changing video playback speed that re-encodes video so file size scales with duration.
